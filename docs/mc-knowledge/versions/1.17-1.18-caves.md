# 1.17–1.18：洞穴与悬崖（高度 / 新方块）

**版本**：Java 1.17 Caves & Cliffs Part I（2021）、1.18 Part II（2021）  
**关键词**：铜、深板岩、紫晶、滴水石、苔藓；**世界高度 -64～319**；刷怪光照变严。

参考：[Java Edition 1.17](https://minecraft.wiki/w/Java_Edition_1.17)、[Java Edition 1.18](https://minecraft.wiki/w/Java_Edition_1.18)。

---

## 高度与地形（1.18 落地）

| 项目 | 值（Java 1.18+，含 26.3） |
|------|---------------------------|
| 最低建筑 Y | **-64** |
| 最高建筑 Y | **319** |
| 总高度跨度 | 384 格 |
| 基岩 | 底部多层基岩区（具体层数以版为准） |

对建筑 AI：

- `terrain=mountain`：可利用更高山峰与悬崖吊脚。  
- 地下城可下探到负 Y；深板岩层成为「地下风格」主材。  
- 旧「建到 Y=256 到顶」的习惯作废。

1.17 开发中曾实验加高，正式加高在 **1.18**。写版本门槛时：**用到 -64/319 就标 ≥1.18**。

## 1.17 新方块（建筑向）

### 铜家族（会氧化）

- `copper_ore` / 深板岩铜矿（生成向）  
- `copper_block`、`cut_copper`、楼梯台阶  
- 风化四级：未氧化 → exposed → weathered → oxidized  
- **涂蜡** `waxed_*` 锁定外观  
- `lightning_rod` 避雷针（屋顶装饰 + 机制）

> 1.21 又大扩铜门/格栅/灯泡等，见 [1.21-26.x.md](1.21-26.x.md)。1.17 只有「块/切制铜」主干。

### 深板岩家族

- `deepslate`、`cobbled_deepslate`  
- 抛光 / 砖 / 瓦 / 錾制及楼梯台阶墙  
- 裂纹变体  
- 深色现代风、地下城、工业风底座

### 紫晶与方解石

- `amethyst_block`、`budding_amethyst`、簇/芽（装饰；芽会生长）  
- `calcite`、`smooth_basalt`（紫晶洞外圈）  
- `tinted_glass` 遮光玻璃——做暗室/影院好用

### 滴水石

- `dripstone_block`、`pointed_dripstone`  
- 钟乳石风室内、洞穴基地；尖滴水石有伤害与落水机制

### 苍郁洞穴植物

- `moss_block`、`moss_carpet`  
- `azalea`、`flowering_azalea`、树叶  
- `spore_blossom`、洞穴藤蔓与发光浆果  
- 垂根、根系泥土等——「地下花园」题材

### 其它

- 蜡烛 `candle` 及染色蜡烛（可堆叠照明，有状态）  
- 细雪 `powder_snow`（陷阱/雪景；实体会沉）  
- 原矿块 `raw_iron_block` 等（仓储风装饰）

## 1.18 机制变更（建筑强相关）

| 变更 | 影响 |
|------|------|
| 洞穴/山地重噪声 | 旧世界坐标上的山腰建筑可能悬空或深埋 |
| 含水层 aquifers | 地下空间更多不规则水体 |
| 敌对刷怪 **方块光 0** | 室内火把防刷更容易；刷怪塔平台必须全黑（见 farms 篇） |
| 矿物分布重做 | 不影响导出 ID，影响生存取材叙事 |

---

## 失效 / 变更摘要

1. 超平坦 / 旧自定义世界高度设定要迁移。  
2. 「光级 ≤7 刷敌对」思路失效。  
3. 仅 1.17 方块、却依赖 1.18 地形的混合标注要分开。  
4. 铜未涂蜡会在世界中继续氧化——**展示用建筑建议生成 waxed_***。

---

## 对 AI 与 `.litematic`

1. **地下风调色板**：cobbled_deepslate + polished_deepslate + moss + dripstone + amethyst 点缀。  
2. **铜建筑**：默认输出 `waxed_cut_copper` / `waxed_copper_block`，避免玩家打开档发现「隔天变绿」。  
3. **蜡烛、尖滴水石、避雷针** 朝向/层数状态多；无 state 模型慎用或后处理。  
4. **tint glass** 适合刷怪周边的观察窗（挡光）。  
5. 条件标签：`terrain=cave` / `underground` → 提高深板岩与苔藓权重；`mountain` → 石+铜避雷针屋顶。
