# 1.14–1.15：村庄与蜂巢（建筑向）

**版本**：Java 1.14 Village & Pillage（2019-04）、1.15 Buzzy Bees（2019-12）  
**目标版语境**：companion **26.3** 仍完整保留这些方块。

参考：[Java Edition 1.14](https://minecraft.wiki/w/Java_Edition_1.14)、[Java Edition 1.15](https://minecraft.wiki/w/Java_Edition_1.15)。

## 1.14 新方块（建筑 / 室内向）

### 工作站与「村民风」家具

| 方块 | ID 示例 | 建筑用途 |
|------|---------|----------|
| 制图台 | `cartography_table` | 图书馆、探险家小屋 |
| 堆肥桶 | `composter` | 农场角、有机风装饰 |
| 锻造台 | `smithing_table` | 铁匠铺（注意 1.20 锻造逻辑后来大改，块本身还在） |
| 烟熏炉 | `smoker` | 厨房，烤食物更快 |
| 高炉 | `blast_furnace` | 冶炼室，炼矿更快 |
| 砂轮 | `grindstone` | 武器店、冒险者公会 |
| 针织台 | `loom` | 染色/旗帜工坊 |
| 讲台 | `lectern` | 教堂、书房（可放书） |
| 石切机 | `stonecutter` | 石匠铺；生存里切楼梯台阶很香 |
| 木桶 | `barrel` | 仓储，比箱子省空间、可含水场景用 |
| 钟 | `bell` | 村庄中心、钟楼 |
| 营火 | `campfire`（灵魂营火见 1.16） | 营地、烟柱地标；可做饭 |

另有 **脚手架** `scaffolding`（竹+线）：临时施工结构；生成「永久建筑」时一般不要当承重墙。

### 新石材 / 装饰砖

1.14 大扩「石匠语汇」，常用包括：

- 安山岩/闪长岩/花岗岩的抛光与楼梯台阶墙变体（许多在周边小更补齐，**以注册表为准**）
- 砖块、石砖变体更成套  
- 新花与染色相关装饰（建筑点缀）

> 完整「哪一版补了哪一级楼梯」若要做白名单，用 [ai-safe-palette.md](ai-safe-palette.md) + 游戏内创造搜索核对。

### 竹与丛林

- 竹子 `bamboo`、竹笋丛等：竖向装饰、脚手架原料。  
- **竹木套装整包**要到 1.20 才齐（见 [1.19-1.20.md](1.19-1.20.md)）。1.14 只有竹子植株本身，不要生成 `bamboo_planks` 却标成「仅 1.14」。

## 1.14 新特性（影响建筑布局）

| 特性 | 说明 |
|------|------|
| 村庄按生物群系换皮 | 平原/沙漠/雪原/萨瓦纳/针叶林等不同屋顶与主材 |
| 掠夺者前哨站 / 袭击 | 防御向建筑（墙、箭塔）题材变多 |
| 职业站点方块 | 室内要给村民留「工作站」格，别做成纯装饰死屋 |
| 纹理更新（同期） | 观感变了；ID 主体仍是 Flattening 后体系 |

---

## 1.14 失效 / 变更

- **旧村庄结构与探测逻辑大改**：1.13 前「门探测铁傀儡塔」等技术大量失效。  
- 交易表重做：生成「村民交易所」时别抄极老价格表。  
- 对纯体素外墙影响小；对「能运转的村庄」影响大。

## 1.15 新方块（建筑向）

| 方块 | ID | 用途 |
|------|-----|------|
| 蜂巢（人工） | `beehive` | 田园、屋顶花园 |
| 蜂窝块 | `honeycomb_block` | 暖色装饰块 |
| 蜂蜜块 | `honey_block` | 减速/粘滑；也可当「琥珀」装饰 |
| 蜂巢（自然） | `bee_nest` | 树侧生成；搬运用精准采集 |

营火可灭火铲灭等小改；发射器可收蜂蜜——偏红石/农场。

## 对 AI 与 `.litematic`

1. **中世纪 / 村庄风格**：优先石匠块 + 工作站 + 营火/桶，避免空壳房间。  
2. **脚手架**：训练里若大量出现，采样后应替换成木板/原木，或标为临时层删掉。  
3. **1.14 标签不要启用竹木全套**：竹木 ID 属于 1.20+。  
4. **钟、讲台、工作站**有方块实体/状态；当前 VAE 可能只出「样子像」的实心块——导出后可用替换表换成真工作站。  
5. companion 26.3：上述 ID 均可用。
