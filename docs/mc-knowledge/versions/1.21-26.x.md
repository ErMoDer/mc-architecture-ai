# 1.21–26.x：试炼、铜扩族与年号制（至 26.3）

**覆盖**：Java **1.21** Tricky Trials（2024-06）及其 1.21.x 投放，以及 **26.1 / 26.2 / 26.3**（年号制）。  
**companion 对齐**：**26.3 Wilderness Bound**。

参考：[Java Edition 1.21](https://minecraft.wiki/w/Java_Edition_1.21)、[Java Edition 26.3](https://minecraft.wiki/w/Java_Edition_26.3)、[version history](https://minecraft.wiki/w/Java_Edition_version_history)。

## 1.21 新方块（建筑向）

### 铜家族扩展

在 1.17 铜块基础上增加（均有氧化与 `waxed_`）：

| 块 | 用途 |
|----|------|
| `chiseled_copper` | 雕纹立面 |
| `copper_grate` | 透光隔断、工业风地板（可透光/部分红石性质以版为准） |
| `copper_bulb` | 红石切换的灯；氧化越深越暗 |
| `copper_door` / `copper_trapdoor` | 铜门体系 |

**展示建筑建议始终用 waxed_，避免氧化抽奖。**

### 凝灰岩家族扩展

- `tuff` 楼梯/台阶/墙、`chiseled_tuff`  
- `polished_tuff` + 楼梯台阶墙  
- `tuff_bricks` + 錾制 + 楼梯台阶墙  

试炼密室大量用铜+凝灰岩——「试炼风」调色板可直接抄结构比例。

### 合成器

- `crafter`：红石脉冲合成并弹出  
- 工厂建筑的核心块；需要朝向与红石配套（见 redstone 知识库）

### 其它

- 试炼刷怪器、宝库、沉重核心等——偏玩法/结构，一般不当普通墙体刷进住宅 AI。  
- 重锤与附魔——物品向。

## 1.21.x 建筑向摘要（苍白花园等）

| 内容 | 说明 | 注意 |
|------|------|------|
| **苍白橡木 Pale Oak** | 完整木套装 + 苍白苔藓等（Garden Awakens 一系） | ID 形如 `pale_oak_planks`；生成「苍白/诡异森林风」用 |
| 树脂等 | 装饰与合成中间物 | 用前在 26.3 创造里确认 |
| 其它小更方块 | 落叶、萤火虫灌木等 | 点缀用；**待核实**是否全部进你模组包 |

> 1.21.x 投放极密。写进导出白名单前，用 `/give` 或创造搜索在 **26.3** 客户端确认一次。

## 26.3 新方块（companion 当前版，建筑向）

### 杨木 Poplar 套装

斑驳森林（dappled forest）主木种，示例：

```
poplar_log, stripped_poplar_log, poplar_wood, stripped_poplar_wood,
poplar_planks, poplar_stairs, poplar_slab, poplar_fence, poplar_fence_gate,
poplar_door, poplar_trapdoor, poplar_sign, poplar_hanging_sign,
poplar_button, poplar_pressure_plate, poplar_shelf, poplar_sapling
```

树叶为红/橙/黄三色杨叶（具体 ID 以客户端为准，写入前核对）。

### 彩色结构件（26.3 大礼）

- **16 色羊毛楼梯与台阶**：如 `white_wool_stairs`、`red_wool_slab`（可消振，偏软装/舞台）  
- **16 色混凝土楼梯与台阶**：硬装立面终于能和混凝土同色衔接  

### 营地与杂项

- `straw_bed`：草垫床（一次性、不重设出生点；下界/末地使用会毁）  
- `red_shrub`、架生蘑菇（shelf mushroom）  
- **坐垫 cushion：实体**，不要当普通方块写进 `.litematic`  
- 废弃营地结构：抄野外营地构图与羊毛楼梯用法

## 失效 / 变更注意

1. 资源包 / 数据包 / 协议号随 1.21→26.x 升高；Litematica、Fabric、companion 需匹配 **26.3**。  
2. 部分 26.3 新 tag（流体/运动）wiki 标注「暂无效果」——依赖它们的包可能空转，**待核实**。  
3. 旧投影缺杨木/羊毛楼梯 ID 时，进 26.3 可能变空气或报未知方块——导出前做映射。  
4. 试炼刷怪器 ≠ 自然刷怪塔规则。

## 对 AI 与 `.litematic`

| 目标风 | 主材建议 | 最低版本意识 |
|--------|----------|--------------|
| 试炼 / 铜厅 | waxed 铜门格栅灯泡 + tuff_bricks | ≥1.21 |
| 苍白花园 | pale_oak + pale moss 等 | ≥1.21.4 左右（以正式加入为准） |
| 秋林 / 斑驳 | poplar + 红灌木 + 彩色叶 | **26.3** |
| 彩色现代 | 混凝土楼梯台阶 + 铜 | 混凝土楼梯要 **26.3**；铜门要 1.21 |

流水线建议：

1. 采样后跑 **目标版 ID 校验**（未知 → 近亲替换）。  
2. `target_version=26.3` 写入导出元数据。  
3. 条件标签 `style=autumn` 时可把 `oak_*` 后处理映射为 `poplar_*`。
