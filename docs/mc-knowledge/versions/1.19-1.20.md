# 1.19–1.20：荒野与旅途传说（建筑向）

**版本**：Java 1.19 The Wild（2022）、1.20 Trails & Tales（2023）  
**主题**：红树/泥巴/幽匿；樱花/竹木/吊牌/考古学装饰。

参考：[Java Edition 1.19](https://minecraft.wiki/w/Java_Edition_1.19)、[Trails & Tales](https://minecraft.wiki/w/Trails_%26_Tales)。

---

## 1.19 新方块（建筑向）

### 红树套装

完整木套装 + 特色：

- `mangrove_log` / `stripped_mangrove_log` / `mangrove_wood`  
- `mangrove_planks` 及楼梯台阶栅栏门活板告示牌按钮压力板  
- `mangrove_roots`、`muddy_mangrove_roots`  
- `mangrove_leaves`、`mangrove_propagule`（胎生苗）

**风格**：沼泽码头、水上吊脚、暗红木+泥砖。

### 泥巴系列

- `mud`、`packed_mud`、`mud_bricks` + 楼梯台阶墙  
- 与红树根系超搭；也可做干旱土坯风（配临近生物群系）

### 幽匿 / 深暗（慎用）

- `sculk`、`sculk_vein`、`sculk_catalyst`、`sculk_shrieker`、`sculk_sensor`  
- `reinforced_deepslate`（古城）  
- 蛙明灯 `ochre_froglight` / `verdant_froglight` / `pearlescent_froglight`（亮彩室内）

> 幽匿传感器会侦测振动——和红石工厂、羊毛消音强相关。生成「深暗神殿」可以；生成「安静的卧室」别乱铺传感器。

### 其它

- 蛙卵、红树相关船等（玩法向）  
- 1.19.x 实验包曾预览部分 1.20 块——**正式生存以 1.20 启用为准**。

## 1.20 新方块（建筑向）

### 樱花套装

- `cherry_log`、`cherry_planks`、楼梯台阶门等全套  
- `cherry_leaves`（花瓣粒子）  
- `cherry_sapling`、`pink_petals`  
- 生物群系：樱花树林——东亚/神社/庭院风第一选择

### 竹木套装

- `bamboo_block`、`stripped_bamboo_block`  
- `bamboo_planks`、`bamboo_mosaic` 及楼梯台阶  
- 门、活板、栅栏、告示牌、吊牌等  
- 与 1.14 竹子植株区分：现在才有「真竹木建筑」

### 吊牌与雕纹书架

- 各木头的 `*_hanging_sign`  
- `chiseled_bookshelf`（可藏书；比较器可读——谜题房）

### 考古学与故事向装饰

- `decorated_pot`（陶罐，面纹状态复杂）  
- 可疑的沙/砾石（玩法）  
- 盔甲纹饰与锻造模板（物品向；铁匠铺展示）  
- 嗅探兽植物：火炬花、瓶子草等点缀

### 标定幽匿传感器

- `calibrated_sculk_sensor`（紫晶校准）——红石向，建筑可做「魔法阵」外壳

## 失效 / 变更

- 1.20：**钻石装备直接锻下界合金**的旧方式失效 → 要锻造模板（物品流程）。  
- 深暗刷怪与监守者：**不是**传统水瀑塔思路。  
- 实验性数据包开启与否会导致「同是 1.19.4 却有无樱花」——以是否正式进主版本为准；**26.3 均已正式包含**。

## 对 AI 与 `.litematic`

1. **风格映射建议**  
   - `swamp` / `water` → mangrove + mud_bricks  
   - `sakura` / `east_asian` → cherry  
   - `bamboo` / `tropical_light` → bamboo_planks + mosaic  
   - `sculk` / `deep_dark` → deepslate + sculk（少而精）  
2. **陶罐、吊牌、雕纹书架** 方块实体/复杂 state 多：可生成外形近似块，再替换表升级。  
3. **花瓣 `pink_petals`** 有层数状态；可当地毯点缀，勿当承重。  
4. 红树根 `mangrove_roots` 可含水——码头好朋友；无 waterlogged 时效果会打折。  
5. 训练数据：MCBlock 若偏欧式中世纪，樱花/红树要靠拉取带标签样本或调色板映射。
