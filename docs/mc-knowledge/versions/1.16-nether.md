# 1.16 下界更新（建筑向）

**版本**：Java 1.16 Nether Update（2020）  
**主题**：下界生物群系重做 + **不燃木** + 黑石/玄武岩调色板。

参考：[Nether Update](https://minecraft.wiki/w/Nether_Update)、[Java Edition guides/Nether Update](https://minecraft.wiki/w/Java_Edition_guides/Nether_Update)。

---

## 新方块（建筑向核心）

### 绯红 / 诡异「木」套装（不燃烧）

完整木制品思路与主世界类似，但原料是 **菌柄 stem / 菌核 hyphae**：

| 系列 | 示例 ID |
|------|---------|
| 绯红 | `crimson_stem`、`stripped_crimson_stem`、`crimson_hyphae`、`crimson_planks`、`crimson_stairs`、`crimson_slab`、`crimson_fence`、`crimson_fence_gate`、`crimson_door`、`crimson_trapdoor`、`crimson_sign`、`crimson_button`、`crimson_pressure_plate` |
| 诡异 | `warped_*` 同上结构 |

配套地表/植被（装饰）：

- `crimson_nylium`、`warped_nylium`  
- `nether_wart_block`、`warped_wart_block`  
- `shroomlight`（亮 15，下界顶灯神器）  
- 菌类、根、垂泪藤、扭曲藤等  

> 注意：下界木 **不能**当普通木全盘假设（例如部分配方/船等差异以目标版为准）。建筑外壳按「不燃木板+菌柄」即可。

### 黑石家族

| 块 | 用途 |
|----|------|
| `blackstone` | 下界「圆石」感；可做熔炉等部分配方替代（生存向） |
| `polished_blackstone` 及砖/錾制/裂纹 | 深色城堡、堡垒风 |
| 对应楼梯、台阶、墙、按钮、压力板 | 成套立面 |

堡垒遗迹（bastion）是绝佳参考调色板：黑石 + 镀金黑石 `gilded_blackstone` + 锁链等。

### 玄武岩

- `basalt`、`polished_basalt`（有朝向）  
- 柱、地板、熔岩三角洲风建筑  
- 1.17 另有 `smooth_basalt`（紫晶洞相关）——生成时注意版本下限

### 灵魂系照明与地面

- `soul_soil`、`soul_torch`、`soul_lantern`、`soul_campfire`  
- 蓝色火光：仪式感建筑、亡灵主题  
- 灵魂沙/灵魂土上的火与速度效果——走道设计要当心

### 其它常用

- `crying_obsidian`、`respawn_anchor`（锚点房间）  
- `target`（红石/训练场）  
- `ancient_debris` / `netherite_block`（奢华点缀，少用）  
- `chain`（吊灯、悬空走廊）  
- 錾制/裂纹下界砖等小扩展

## 新特性（影响选址与风格）

| 点 | 建筑含义 |
|----|----------|
| 下界多生物群系 | 绯红森林 / 诡异森林 / 灵魂沙峡谷 / 玄武岩三角洲 → 不同主色 |
| 堡垒与堡垒仓 | 可抄黑石比例与拱券 |
| 床在下界爆炸 | 宿舍要用重生锚；26.3 草垫床规则不同，见 breaking-changes |
| 猪灵/疣猪兽 | 安全区与栅栏设计（玩法向） |

## 失效 / 变更

- 旧「走廊式下界」地形与导航失效；旧坐标基地可能埋进熔岩海或新生物群系。  
- 只带「下界残骸」思维的调色板过时——应加入菌柄木与黑石。  
- 石英仍可用，但不再是下界唯一亮色装饰。

---

## 对 AI 与 `.litematic`

1. **风格标签 `nether` / `inferno`**：词表应含 crimson/warped/blackstone/basalt/shroomlight。  
2. **不要混用主世界橡木屋顶 + 下界地板**除非刻意做「门户」对比。  
3. **菌柄有 axis**；黑石砖楼梯有 facing——无 state 时优先用 planks、wart block、shroomlight 等「不太挑朝向」的块做主体。  
4. **火焰**：下界木不燃，但灵魂火与熔岩仍烤实体；生成物别把灵魂营火塞进人行道正中。  
5. 旧 MCBlock 数据若偏主世界，下界风要靠条件生成 + 调色板替换（橡木→绯红木板、石砖→抛光黑石砖等）。

## 小调色板示例

**堡垒风**：`polished_blackstone_bricks` + `blackstone` + `gilded_blackstone` + `chain` + `lantern`/`soul_lantern`  
**诡异花园**：`warped_planks` + `warped_stem` + `warped_wart_block` + `shroomlight`  
**熔岩三角洲碉堡**：`basalt` + `blackstone` + `magma_block`（少许）
