# 建筑相关：破坏性变更与失效项

写给「导出投影 / 生成方块 / 旧图升级」：哪些东西**不能再按老办法用**。  
范围：Java，侧重 1.13 → 26.3。命令与数据包细节从略（另文待写）。

---

## 1. 方块与物品 ID：Flattening（1.13）——最大坑

### 失效了什么

- **数字方块 ID**（如 `5` = 木板）与 **damage / metadata**（如 `5:1` = 云杉木板）在 Java 正式玩法中作废。
- 许多「一个 ID + 元数据」拆成多个方块，例如：
  - 木板 → `oak_planks`、`spruce_planks`、…
  - 石头台阶/双台阶变体 → 独立 `*_slab` 方块
  - 花、染料、床等大量拆分
- 生物群系 ID 字符串也大量重命名（如 `hell` → `nether`）。

### 还在用的正确方式

```text
minecraft:oak_planks
minecraft:stone_bricks
# 含水是方块状态，不是老式「水+方块」混 ID
waterlogged=true
```

### 对建筑 AI

- 词表、`.mcfunction`、`setblock`、Litematica 一律 **namespaced ID**。
- 旧 schematic（WorldEdit `.schematic` 数字 ID）进现代 Java 必须转换；本项目优先 **`.litematic` + 现代 ID**。
- 不要发明不存在的 ID（如 `minecraft:wood_planks`）。

## 2. 含水与流体（1.13+）

| 点 | 说明 |
|----|------|
| `waterlogged` | 楼梯、台阶、栅栏、活板门、箱子等可含水 |
| 流动水/静止水 | 玩法上合并为水 + 等级状态；旧 `flowing_water` 方块概念失效 |
| 导出 | 码头/海底建筑若忽略 `waterlogged`，进游戏会「缺水」或形状不对 |

**对建筑 AI**：水体附近结构，要么后处理灌水，要么在体素里显式存含水态（当前 VAE 若只存方块种类、不存 state，码头类会弱——已知限制）。

## 3. 世界高度与地形（1.18）

| 变更 | 影响 |
|------|------|
| 建筑高度 **-64～319** | 旧「建到 256 顶」的习惯要改；基岩层位置变了 |
| 洞穴/山地重做 | 旧坐标上的「山腰小屋」可能悬空或埋进新地形 |
| 敌对刷怪 **方块光须为 0**（多数敌对） | 旧照明设计「光级≤7 才刷」失效；室内火把防刷更容易 |

**对建筑 AI**：`terrain=mountain` 要考虑悬崖、支撑柱；地下建筑注意与 -64 基岩的关系。

---

## 4. 下界（1.16）

- 下界生物群系与地形重做：旧「走廊式下界」导航与基地位置可能失效。
- 普通床在下界仍会爆炸。
- 26.3 的草垫床 `straw_bed`：**尝试在下界/末地使用会被破坏且不爆炸**（与普通床不同）。建造逻辑里不要把两种床混成同一套「安全/危险」规则。
- 绯红/诡异木按完整木套装生成即可；个别物品（如船）以目标版注册表为准。

---

## 5. 锻造与装备（1.20）

- 钻石工具直接上下界合金的旧配方失效 → **锻造模板**。
- 对纯建筑体素导出影响小；若生成「铁匠铺」战利品/展示，需用新物品逻辑（待写物品篇）。

## 6. 红石与机械相关变更（摘要）

| 版本 | 点 | 建筑/机械影响 |
|------|----|----------------|
| 较早期 → 现代 | QC（准连接）、活塞时序有长期行为，版本间偶有修复 | 复制极老红石电路可能差 1 tick |
| 1.19 | 幽匿传感器 / 校准传感器 | 振动可触发；羊毛/地毯消音成为建筑要素 |
| 1.21 | **合成器 `crafter`** | 可做自动合成建筑；需红石脉冲投出 |
| 1.21 | 活塞声音调小等 | 不影响功能 |
| 26.3 | 部分流体/运动相关 block tag 仍在迭代（wiki 注有「目前无效果」的 tag） | 依赖新 tag 的包可能未生效——**待核实** |

详情见 `../redstone/`。

## 7. 刷怪与农场（摘要）

| 版本 | 失效/变更 |
|------|-----------|
| 1.18 | 「光级 1–7 还刷敌对」基本没了 → 须暗到方块光 0 |
| 1.18+ | 世界更高、洞穴更多 → 地表塔要更注意周边洞穴抢帽 |
| 1.19 | 深暗之域 / 监守者 —— 不是传统刷怪塔思路 |
| 1.21 | 试炼刷怪器 / 宝库 —— 与自然敌对帽不同机制 |

详情见 `../farms/mob-spawning-basics.md`。

## 8. 结构与村庄

- **1.14** 村庄重做：1.13 及更早的「旧村庄」与新城规划不同；探测村庄门/铁傀儡农场等旧技术大量失效。
- **1.21** 试炼密室：新的地下结构与铜/凝灰岩主题。
- **26.3** 废弃营地：多生物群系变种，含羊毛楼梯、草垫床等——可作「野外营地」生成参考。

---

## 9. 资源包 / 数据包 / 协议（导出周边）

升级客户端或 Fabric 时：

- 资源包 `pack_format`、数据包 format 随版本升高；旧包要更新或自动转换。
- Litematica / WorldEdit / companion 需与 **26.3** 匹配；版本不够新时会表现为「放置空气 / 未知方块」。

**对建筑 AI**：导出流水线应记录 `target_version`（当前 26.3）；抽样建造失败时先查「ID 是否存在于该版」。

---

## 10. 常见「看起来还能用其实已坏」清单

1. 数字 ID schematic 直接塞进 1.13+ Java  
2. 用 `planks`、`wool`（无颜色）等已拆分的旧 ID  
3. 按 1.17 及更早的光照思路设计刷怪室（光级≤7）  
4. 1.13 前的村庄门探测铁傀儡塔  
5. 假设所有木套装属性完全一致——以目标版注册表为准  
6. 把 **坐垫 cushion** 当普通方块写进 `.litematic`（26.3 里它是实体）  
7. 在生成物里写未公布/猜测的方块名
