# 凝灰岩系（Tuff）建筑族

**用途**：1.21 试炼密室灰调石材；洞穴/地下建筑中性基底。

## 方块树

```
tuff
 ├─ tuff_stairs / tuff_slab / tuff_wall
 ├─ chiseled_tuff
 ├─ polished_tuff → stairs / slab / wall
 └─ tuff_bricks → stairs / slab / wall / chiseled_tuff_bricks
```

工作台或切石机均可；试炼密室大量使用砖与磨制变种。

---

## 生成与配色直觉

- 主世界 Y≤0 附近凝灰岩团块；26.2 起亦见于硫黄泉相关生成。
- 色调：灰褐、低饱和 → 配铜青锈、深板岩、黑色混凝土对比强。
- 不可再生基岩（团块），建筑包用库存/创造即可。

---

## AI 用法

| 场景 | 建议 |
|------|------|
| 试炼风地牢 | `tuff_bricks` 墙 + `polished_tuff` 地 + waxed 铜装饰 |
| 现代灰墙 | `polished_tuff` + 浅色混凝土楼梯（26.3） |
| 旧版导出 | → `deepslate_bricks` / `stone_bricks` |

最低版本：**楼梯/墙/砖族约 1.21**（实验包更早快照）。
