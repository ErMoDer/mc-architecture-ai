# 红石版本差异摘要（建筑 / 电路向）

面向「换版本后电路坏了」和「生成装置该标最低版本」。  
默认对照 **Java**，终点 **26.3**。数值若与客户端不符，以实测与 wiki 为准，并标 **待核实**。

前置：[components.md](components.md)、[qc-bud.md](qc-bud.md)。

---

## 总原则

1. **QC / 活塞短脉冲粘性行为** 是 Java 长期特色；Bedrock 另说。  
2. 新组件（观察者、目标块、幽匿、铜灯泡、合成器）会**替换**一批老麻烦设计，而不是删掉粉尘规则。  
3. 实验数据包可能改粉尘更新范围——启用前当作「另一规则集」。  
4. 建筑导出只保证方块 ID；**时序正确性**要靠模板版本号，例如 `circuit_schema=java_1_21_plus`。

---

## 时间线（电路向）

| 版本 | 变化 | 对建筑/电路 |
|------|------|-------------|
| 早期～现代 | QC、粘性活塞短脉冲「推不拉」 | Java 隐藏门、T 触发基础 |
| **1.5** | 比较器加入并定型延迟 | 容器读取、减法、模拟信号 |
| **1.11** | **观察者** | 大量 BUD 可简化；甘蔗农场现代化 |
| **1.14** | 工作站、堆肥桶等可读/可用 | 比较器装饰谜题增多 |
| **1.16** | **目标方块**；灵魂营火等 | 弹射物开关；下界机房 |
| **1.17** | 铜、粉末雪等 | 避雷针充能；铜氧化可被观察者看见 |
| **1.19** | **幽匿传感器** | 振动红石；羊毛消音成建筑要素 |
| **1.20** | **校准传感器**、紫晶共振、双侧告示牌等 | 过滤振动；谜题房 |
| **1.21** | **合成器**、**铜灯泡**、铜格栅等 | 工厂脉冲合成；1 格 T 触发 |
| **1.21.x** | 小更与实验 | 以正式启用组件为准 |
| **26.3** | 羊毛楼梯/台阶等 | **消振材料**更多；红石主干未改「15 格粉尘」 |

## 分主题对照

### 粉尘与更新

| 点 | 说明 |
|----|------|
| 强度衰减 | 长期：每格 -1，最长 15 |
| 粉尘更新范围 | 经典 Java 较大，易带 QC；实验性「少更新」曾引发社区争议——**26.3 是否启用实验包待核实** |
| 跨区块 | 未加载区块不保证传导 |

### 活塞与 QC

| 点 | 说明 |
|----|------|
| QC 对象 | 活塞、发射器、投掷器 |
| 短脉冲粘性 | 过短脉冲可能不拉回——T 触发与「失败门」同源 |
| 推限 | 12 格；粘液/蜂蜜团规则多版本微调时**待核实**具体图 |

### 传感器与振动（1.19+）

| 点 | 说明 |
|----|------|
| 幽匿传感器相位 | 活跃/冷却长度曾调整；勿背死旧教程秒数 |
| 羊毛消音 | 地毯、羊毛；26.3 起羊毛楼梯/台阶也可纳入消音设计 |
| 与机械房 | 高频活塞旁别开传感器，除非刻意做报警 |

### 铜灯泡与合成器（1.21+）

| 点 | 说明 |
|----|------|
| 铜灯泡 | 脉冲切换；比较器读状态；快照期延迟改过，正式版即时切换 |
| 合成器 | 要**新脉冲**；持续供电不连打；有短冷却相关修复史 |
| 氧化 | 未涂蜡灯泡亮度会变；电路读「亮/灭」一般仍 15/0，但光照叙事会变 |

### 物品与容器

| 点 | 说明 |
|----|------|
| 漏斗锁定 | 长期稳定 |
| 比较器读满度 | 公式长期存在；新容器（如合成器槽位）有自己的刻度 |
| 雕纹书架（1.20） | 比较器可读取书相关信号——谜题/隐藏门 |

---

## 「换版本易坏」清单

1. 依赖粉尘侧更新才唤醒的 QC 活塞（实验红石规则下）。  
2. 用幽匿传感器当「脚步开关」却没做羊毛隔断（邻居走路误触）。  
3. 1.20 前的农场图硬塞校准传感器。  
4. 合成器当熔炉用（持续火）——必须脉冲。  
5. 铜灯泡当红石灯接拉杆长亮——会边缘狂切或不符合预期。  
6. 把 Java QC 门原样丢到基岩版。

## 对 AI 生成的版本标签建议

| 装置类型 | `min_version` 建议 |
|----------|-------------------|
| 纯粉尘+中继器+火把 | 1.13+（现代 ID）即可 |
| 观察者农场 | 1.11+ |
| 目标块开关 | 1.16+ |
| 幽匿门禁 | 1.19+ |
| 铜灯泡 T 触发 / 合成器厂 | **1.21+** |
| 羊毛楼梯消音箱体 | **26.3** |

导出元数据示例：`redstone_min=1.21`；校验器拒绝更低目标版。
