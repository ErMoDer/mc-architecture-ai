# 铜灯泡用于建筑照明（短记）

**用途**：补全「装饰照明」与红石开关灯；非工厂教程。

**来源**
- [Tricky Trials](https://minecraft.wiki/w/Tricky_Trials) / [Block of Copper](https://minecraft.wiki/w/Copper_Block)
- 项目 [components.md](components.md)

---

## 要点

- 合成：对应铜块 + 烈焰棒 + 红石粉 → 铜灯泡（四阶段×涂蜡）。
- 红石脉冲切换亮灭；**不需持续供电**保持状态（以当前 Java 行为为准）。
- 氧化越深，光照越暗 → 建筑包用 `waxed_copper_bulb` 锁定亮度档。
- 住宅 AI：顶棚每 5–8 格一灯；勿与侦测器钟默认绑在一起。

最低版本：约 **1.21**。旧版映射：`lantern` / `sea_lantern`。
