# 红石组件细表（Java / 26.3）

上一篇 [basics.md](basics.md) 讲直觉；这篇当**零件手册**。默认 **Java Edition**，目标环境 companion **26.3**。  
延迟单位：`gt` = game tick（0.05 s），`rt` = redstone tick（2 gt = 0.1 s）。

参考：[Redstone components](https://minecraft.wiki/w/Redstone_components)、[Redstone mechanics](https://minecraft.wiki/w/Redstone_mechanics)。

---

## 1. 粉尘 `redstone_wire` / 红石块 `redstone_block`

| 项 | 内容 |
|----|------|
| 粉尘强度 | 0～15；每传 1 格 **-1**；满电最多 15 格 |
| 粉尘延迟 | 视为 **0 gt**（同 tick 传开；复杂 QC/活塞链另说） |
| 形状 | 点/线/十字；连不连影响是否给侧面组件供电 |
| 弱充能实心块 | 粉尘可点亮下方/相邻实心块，但不一定「强充」到背后粉尘 |
| 红石块 | 恒定强度 15；邻接可直接给组件供电；**不**像中继器那样强充传导 |

**建筑注意**：地板走线要预留沟槽；地毯/半砖可藏线但别挡连接。

---

## 2. 中继器 `repeater`

| 项 | 内容 |
|----|------|
| 功能 | 任意输入强度 → 输出 **15**；续航 + 延迟 |
| 延迟 | 1～4 **rt**（2/4/6/8 gt），右键切换 |
| 锁定 | 侧面被另一中继器或比较器供电时，锁住当前开/关 |
| 脉冲整形 | 高延迟档会拉长过短的「开」脉冲、吞掉过短的「关」 |

**口诀**：要传远、要干净的满电、要固定延迟 → 中继器。

---

## 3. 比较器 `comparator`

| 项 | 内容 |
|----|------|
| 延迟 | 固定 **1 rt（2 gt）** |
| 比较模式 | 后侧 ≥ 两侧较大值 → 输出后侧强度，否则 0 |
| 减法模式 | 输出 = 后侧 − 两侧较大值（≥0） |
| 维持 | 无侧输入时，输出 = 后侧强度（不「加满到 15」） |
| 测量 | 读容器满度、堆肥层、蛋糕、唱片机、铜灯泡亮灭等 → 0～15 |

**Java 坑**：极短（约 2 gt）波动有时吃掉，观察者双脉冲等可逼它响应——精密时序请实测。

---

## 4. 红石火把 `redstone_torch` / 红石灯 `redstone_lamp`

| 项 | 内容 |
|----|------|
| 火把 | 附着块**未充能**时亮；充能则灭 → 天然 **NOT** |
| 火把延迟 | 点亮/熄灭各约 **1 rt** 量级（精确组合以实测为准） |
| 烧毁 | 过高频闪烁会暂时烧掉 |
| 红石灯 | 有电就亮；关灯有短暂延迟（关比开慢一点，常见设计要算进去） |

---

## 5. 观察者 `observer`

| 项 | 内容 |
|----|------|
| 检测 | 正面方块/流体/空气状态变化 |
| 输出 | 背面短脉冲，Java 上常见 **2 gt**、强度 15 |
| 强充 | 可像中继器一样强充输出侧实心块 |
| 典型用途 | 甘蔗/竹子、活塞推拉、门开关、生长检测 |
| 风险 | 两只观察者互盯 → 自激振荡 |

**1.11+** 起稳定存在；很多旧 BUD 可用观察者替代（见 [qc-bud.md](qc-bud.md)）。

---

## 6. 活塞 / 粘性活塞 `piston` / `sticky_piston`

| 项 | 内容 |
|----|------|
| 推动 | 最多推 **12** 格一条线（粘液/蜂蜜规则另算） |
| 粘性 | 缩回时拉回前方块；**极短脉冲**时可能「推了不拉」（Java 特性，做 T 触发常用） |
| QC | **会被上方格充能**（准连接）——Java 专有，见 qc-bud |
| 不可推 | 黑曜石、基岩、部分方块实体等（完整列表见 wiki） |

史莱姆块 / 蜂蜜块：成团移动、黏附规则复杂；做门/飞行器前先查「不可移动/不可黏」表。

---

## 7. 发射器 / 投掷器 `dispenser` / `dropper`

| 项 | 内容 |
|----|------|
| 触发 | 收到红石（含 **QC**：上方格有电）时动作一次 |
| 发射器 | 按物品类型「使用」（箭、船、桶、刷怪蛋…） |
| 投掷器 | 只弹出物品，不「使用」 |
| 朝向 | `facing` 状态关键；AI 无 state 时极易朝错 |

---

## 8. 漏斗 `hopper` / 漏斗矿车

| 项 | 内容 |
|----|------|
| 传输 | 吸入/送出物品；可被红石**锁定**停止 |
| 比较器 | 可读漏斗库存满度 |
| 漏斗钟 | 两漏斗对吐 + 比较器 → 经典时钟/脉冲源 |

建筑里：仓储底层预留漏斗层；别把红石线乱铺在漏斗锁定位上。

---

## 9. 目标方块 `target`（1.16+）

| 项 | 内容 |
|----|------|
| 触发 | 被弹射物击中输出信号；命中越靠中心强度越高 |
| 传导 | wiki：目标方块**本身**的红石行为与普通导电块不同——设计时别当「万能强充块」想当然 |
| 用途 | 射箭开关、训练场、部分紧凑电路重定向 |

---

## 10. 幽匿传感器 / 校准传感器（1.19 / 1.20）

| 项 | 内容 |
|----|------|
| 幽匿传感器 | 侦测振动 → 红石；活跃约 **30 gt**，冷却约 **10 gt**（数值以 wiki 为准） |
| 校准版 | 紫晶校准；可过滤频率；范围更大、相位更短 |
| 消音 | 羊毛、地毯、以及 26.3 的**羊毛楼梯/台阶**等可抑制振动传播 |
| 紫晶块共振 | 邻接时可再发射振动——小心连环触发监守者 |

---

## 11. 铜灯泡 `copper_bulb`（1.21+，26.3 可用）

| 项 | 内容 |
|----|------|
| 行为 | 每次收到红石**脉冲沿**切换亮/灭；**不需要持续供电**保持发光 |
| 亮度 | 随氧化降低；建筑展示请用 `waxed_*` |
| 读出 | 比较器：亮=15，灭=0 → 超紧凑 **T 触发** |
| 观察者 | 可检测「正在被充能」的红点状态变化 |

开发快照里曾有 1 gt 切换延迟，后改为即时——以正式 1.21+ / 26.3 为准。

---

## 12. 合成器 `crafter`（1.21+）

| 项 | 内容 |
|----|------|
| 触发 | **新脉冲**合成并向前弹出（持续高电平不会一直合） |
| 比较器 | 可读槽位占用（约 0～9 相关，以 wiki 为准） |
| 漏斗 | 可输入/取出 |
| 朝向 | 放置方向 = 输出面 |

适合工厂房；住宅 AI 不要随机洒合成器。

---

## 13. 其它常用

| 组件 | 一句话 |
|------|--------|
| 拉杆/按钮/压力板/绊线 | 输入源；木质/石质按钮脉宽不同 |
| 阳光传感器 | 白天/反转给模拟强度 |
| 音符盒 | 可被观察者/充能触发；做音效门 |
| 讲台 | 翻页可出信号（比较器） |
| 避雷针 | 雷击充能；也能做装饰导电点 |
| 铁轨系 | 动力/探测/激活轨——交通红石 |

---

## 对建筑 AI

- 生成阶段优先放**外壳 + 走线空间**；组件朝向用模板粘贴。  
- 词表若含 `repeater`/`comparator`/`observer`/`piston`，必须有 `facing` 策略。  
- 铜灯泡、合成器：版本门槛 **≥1.21**；导出 26.3 无压力。  

电路拼法见 [circuits-common.md](circuits-common.md)。
