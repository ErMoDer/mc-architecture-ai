# 常用红石电路（Java / 26.3）

用「要干什么 → 怎么搭直觉 → 坑」的方式写。细节尺寸以创造里实测为准；这里给可复述的骨架。  
前置：[basics.md](basics.md)、[components.md](components.md)。

参考：[Redstone circuits](https://minecraft.wiki/w/Redstone_circuits)、[Memory circuits](https://minecraft.wiki/w/Redstone_circuits/Memory)。

---

## 1. 时钟（Clock）

**目的**：周期性开关，驱动农场、灯、发射器。

| 类型 | 骨架直觉 | 周期感 | 注意 |
|------|----------|--------|------|
| 中继器环 | 若干中继器首尾相接成环，需先注入一次电 | 由中继器档位之和决定 | 可锁；断环即停 |
| 比较器钟 | 比较器减法 + 粉尘回路等紧凑布局 | 很快（常见数 gt 级） | 易与其它电路抢更新 |
| 观察者钟 | 观察者对着可更新块（或互看变种） | 极快 | 卡顿与烧毁风险；生存慎用 |
| 漏斗钟 | 两漏斗对吐，比较器读一侧 | 由物品数调节 | 稳定、好调速，偏仓储 |

**建筑**：给时钟单独小房间；高速钟远离卧室（声/卡顿）。

---

## 2. 脉冲延长（Pulse extender）

**目的**：按钮短按 → 灯/活塞保持更久。

常见思路：

1. 输入经中继器串（每只最多 4 rt）累加延迟；  
2. 或用下落沿/充能的火把链；  
3. 或用比较器读容器（漏斗钟式）做长定时。

**坑**：中继器在高档位会「吞」掉比自己还短的关脉冲——既是特性也可当整形器。

---

## 3. 脉冲缩短 / 边沿检测

**目的**：只在「按下瞬间」闪一下（开抽屉、激活一次发射器）。

| 思路 | 说明 |
|------|------|
| 观察者 | 正面看会变的块，背面 naturally 短脉冲 |
| 粉尘短路 | 信号经旁路更快灭掉主路（经典脉冲限制器） |
| 中继器差速 | 两路延迟不同再汇合 |

按钮本身已是脉冲；对拉杆这种「电平」才更常要边沿检测。

---

## 4. RS 锁存（记住开或关）

**目的**：按一次开、按另一次关（或两路输入置位/复位）。

| 经典 | 直觉 |
|------|------|
| 双火把交叉 | 两个火把互锁，S/R 输入拉低一侧 |
| 中继器锁存 | 用中继器锁定保持状态 |
| 活塞锁 | 推块断线/接线（占空间，直观） |

输出应能驱动门、灯、隐藏楼梯。标注好 **SET / RESET**，避免自己绕晕。

---

## 5. T 触发（Toggle / T flip-flop）

**目的**：按一次切换状态（同一按钮开关门）。

| 方案 | 最低版本意识 | 说明 |
|------|--------------|------|
| **铜灯泡 + 比较器** | ≥1.21 | 最紧凑：脉冲 → 灯泡翻转；比较器读亮=15 |
| 粘性活塞短脉冲 | 长久可用 | 利用「短脉冲推了不拉」翻转方块位置 |
| 观察者 + QC 活塞等 | Java | 紧凑但依赖 QC，见 qc-bud |

**建筑推荐（26.3）**：室内开关优先 **涂蜡铜灯泡** 方案，省空间、好藏。

---

## 6. 单向门（二极管 / 防倒灌）

**目的**：信号只许 A→B，不许回流搅时钟。

| 手段 | 说明 |
|------|------|
| 中继器 | 天然单向 |
| 比较器 | 单向，且可保持强度 |
| 火把塔 | 也可隔离，但占高、有延迟 |

总线交叉、多房间共用电源时必做隔离。

## 7. 物品运输相关红石

### 7.1 漏斗锁

- 漏斗被充能 → **停止**吸入/送出。  
- 用中继器/粉尘对准漏斗所在块或其本身（按连接方式）。  
- 做「过滤器」：侧边漏斗 + 命名物品占槽，主流只走一种物品（经典设计，细节略）。

### 7.2 漏斗钟作节奏源

- 稳定农场节奏、合成器脉冲间隔。  
- 物品越少通常越快（具体与布局有关，**待核实**你常用的那款图）。

### 7.3 合成器工厂（1.21+）

```
漏斗输入 → crafter ← 脉冲时钟
                ↓ 弹出
            漏斗/箱子收集
```

- 必须是**脉冲**，长拉杆按住不会连打。  
- 朝向 = 吐出面；预留前方空间。

### 7.4 发射器泵水/弹射

- 发射器 + 水桶 = 临时水源（经典冰农场/飞行器外围）。  
- 投掷器只吐物品，适合纯物流。

### 7.5 矿车

- 探测铁轨读车；激活轨清理实体；动力轨要充能。  
- 车站用比较器读矿车漏斗库存做空满车逻辑。

## 8. 简易「门电路」选型

| 需求 | 推荐 |
|------|------|
| 按钮进出、自动关 | 脉冲延长 + 活塞门，或铜灯泡 T 触发 + 活塞 |
| 密码/多按钮 | RS 锁存串比较器 |
| 隐藏活塞门（齐平） | 常依赖 **QC**（Java）；Bedrock 要换设计 |
| 仅装饰灯 | 拉杆 + 红石灯 / 铜灯泡 |

---

## 9. 调试清单

1. 粉尘是否连成你以为的形状？  
2. 中继器/比较器箭头朝哪？  
3. 有没有意外 QC 点亮上方活塞？  
4. 时钟是否被别处灌电倒灌？加单向。  
5. 铜灯泡是否被持续电平狂抖？（要脉冲）  
6. 区块边界：红石不跨越未加载区块可靠工作。

## 对建筑 AI

- 电路用**预制模板**（Litematica 子投影）粘到建筑预留空洞，而不是体素网络随机学。  
- 标签可加 `has_redstone_room=true`，生成时留 3×3×3 以上机房。  
- 详见 [ai-constraints.md](ai-constraints.md)。

## 10. 逻辑门速查（一行）

| 门 | 直觉搭法 | 备注 |
|----|----------|------|
| NOT | 红石火把 | 见 basics；防烧毁 |
| OR | 多路粉尘汇合 | 注意倒灌，加单向 |
| AND | 两路同时顶同一火把附着块等 | 紧凑方案多，用模板 |
| XOR 等 | 比较器/火把组合 | **不要**让 AI 现场发明 |

比较器比较/减法/读容器见 [basics.md](basics.md)；瞬时线与活塞延伸边界见 [signals-timing.md](signals-timing.md)。
