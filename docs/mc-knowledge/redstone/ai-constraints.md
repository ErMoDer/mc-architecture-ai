# 建筑 AI 的红石约束（别瞎放）

体素模型擅长「好看的墙」，不擅长「对的 tick」。  
本篇规定：**生成建筑时红石可以留位，但不许假装已经会算电路。**

配合：[circuits-common.md](circuits-common.md)、[qc-bud.md](qc-bud.md)、版本库 [ai-safe-palette.md](../versions/ai-safe-palette.md)。

---

## 1. 硬规则（生成器默认）

| # | 规则 |
|---|------|
| 1 | **禁止**在住宅/景观主网格随机刷 `redstone_wire`、中继器、比较器、观察者、活塞 |
| 2 | **禁止**依赖 QC 的隐藏门由 AI 直接生成 |
| 3 | 允许生成 **机房空洞**（标注 `redstone_room`），尺寸建议 ≥ 3×3×3，预留地板夹层 |
| 4 | 机械只通过 **人工模板**（`.litematic` 子投影 / 结构块）粘贴 |
| 5 | 所有红石模板必须带 `min_version` 与 `edition=java` |
| 6 | 铜灯泡、合成器模板：`min_version≥1.21`；导出目标 26.3 OK |
| 7 | 输出朝向敏感块时必须写清 `facing`；写不清就换成灯/块装饰假门 |
| 8 | 不得把 cushion、物品展示框等**实体**当红石方块 |

---

## 2. 允许的「弱红石」装饰

这些可以当装饰块生成（即使暂时不通电）：

- 拉杆、按钮、红石灯（当壁灯造型）  
- 涂蜡铜灯泡（当吸顶灯造型；**不要**接乱线）  
- 目标方块（当靶子装饰）  
- 音符盒（家具）  

事后若要接通，从机房引线，而不是在客厅地板长满粉尘。

---

## 3. 推荐流水线

```
条件采样建筑外壳
    → 方块替换 / 调色板（版本安全）
    → 若标签 needs_door_mechanism：
          粘贴人工「活塞门模板」到预留洞
    → 若 tags 含 factory：
          粘贴合成器+漏斗模板
    → 导出 litematic → companion 建造
    → 创造模式实测 10 次开关
```

失败则回滚模板，不改 AI 权重瞎补粉尘。

---

## 4. 标签约定（建议）

| 标签 | 含义 | 生成行为 |
|------|------|----------|
| `redstone=none` | 默认 | 无红石组件 |
| `redstone=decor` | 装饰开关/灯 | 仅弱红石 |
| `redstone=room` | 预留机房 | 空洞+告示牌标注 |
| `redstone=template:door_v1` | 指定模板 | 粘贴门电路 |
| `redstone=template:crafter_line` | 工厂 | 粘贴合成线 |

---

## 5. 空间预留指南

| 装置 | 预留 |
|------|------|
| 简单按钮门（非齐平） | 门侧 1×2 壁龛走线 |
| 齐平活塞门（QC 模板） | 整面墙后 2 格机腔 + 顶上 1 格清 QC |
| 铜灯泡 T 触发 | 1×2 即可（灯泡+比较器） |
| 漏斗钟 | 2×2 地板下 |
| 合成器线 | 长条：输入箱-漏斗-合成器-输出，前方空 1 格 |

---

## 6. 质量门禁（导出前）

- [ ] 无「悬浮中继器箭头朝地心」  
- [ ] 无活塞头顶误铺红石灯座（除非模板需要）  
- [ ] 时钟不与床同房  
- [ ] 幽匿传感器不与高频农场同振动区（或已羊毛包裹）  
- [ ] 模板 `min_version` ≤ companion `MC_VERSION`（26.3）  

---

## 7. 为什么要这么严

1. 错电路比空壳建筑更难修。  
2. QC 失败表现为「有时动有时不动」，用户以为是 companion bug。  
3. 训练数据里的机械装置往往不完整，模型会学到「活塞插在屋顶当装饰」。  

先把建筑美学做稳，红石用模板库迭代——和「方块替换 → 调色板 → 条件生成」的产品顺序一致。

## 8. 原理文档与能力边界（2026-10-19）

可读摘要：`powering-charging` / `block-updates` / `tile-ticks` / `signals-timing`。  
这些文档解释**玩家与模板作者**需要知道的因果；**不**授权生成器实现完整原版更新/计划刻引擎，也**不**授权发明 instant wire、BUD、更新抑制桥。机械仍走 §3 模板流水线。
