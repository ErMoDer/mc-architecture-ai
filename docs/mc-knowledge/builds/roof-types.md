# 屋顶类型速查摘要（改写）

**用途**：常见屋顶类型的**短定义 + 生成侧选用表**。不复制 Wiki 图文教程。

**来源**：[Tutorial: Roof types](https://minecraft.wiki/w/Tutorial:Roof_types)

---

## 本阶段实际会用的

| 类型 | 一句话 | look_harden |
|------|--------|-------------|
| **平顶 / 女儿墙顶** | 封平 + 边框异材更像「真屋顶」 | `industrial/modern/scifi/desert` 平顶 |
| **双坡（gable）** | 倒 V；小屋与村庄风常用 | 坡顶风格默认 |
| **单坡 / 披屋** | 只向一侧倾斜；辅房、廊 | 未单独实现（可后加） |
| **四坡（hip）** | 四向落坡；阁楼体积小 | 未实现（32³ 成本高） |

## 仅作知识、暂不自动生成

盐盒、天窗层、孟莎、锯齿厂房屋顶、蝶形、盔顶、阁楼窗（dormer）等：术语收入知识库，**当前后处理不建模**。需要时优先人工模板或更大分辨率。

## 材料提示（摘要）

- 平顶边框尽量与墙身**换材质**（半砖/倒楼梯作檐沟感）。
- 茅草/绿顶等主题用调色板表达，不在几何里硬编码。

## 与 shape-language 的关系

立面层次、楼梯/半砖收边见 [shape-language.md](shape-language.md)；本页只管「屋顶叫什么、何时用」。
