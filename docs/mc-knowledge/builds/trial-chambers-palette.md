# 试炼密室建筑语汇（调色，非攻略）

**用途**：生成「试炼风」室内/地牢走廊时的方块组合；不包含刷怪笼机制详解。

**来源**
- [Trial Chambers](https://minecraft.wiki/w/Trial_Chambers)
- [Tricky Trials](https://minecraft.wiki/w/Tricky_Trials)
- [Tuff](https://minecraft.wiki/w/Tuff)

---

## 核心材料

- **石**：`tuff_bricks`、`polished_tuff`、`chiseled_tuff` / `chiseled_tuff_bricks`、深板岩点缀。
- **金属**：各阶段 **waxed** 切制铜、格栅、灯泡、门。
- **其他**：铜灯泡作顶灯；格栅作通气/地板透光；避免大量未涂蜡铜。

---

## 空间节奏（AI）

1. 走廊：砖墙 + 磨制地 + 间歇铜灯。
2. 房间：加高顶、角落雕纹凝灰岩。
3. 入口：铜门或深板岩拱（楼梯倒放）。

不要自动生成试炼刷怪笼/宝库当「装饰」——玩法方块与建筑壳分离。
