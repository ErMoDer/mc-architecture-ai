# 敌对刷怪规则入门（Java）

讲清楚：怪什么时候出现、为什么你的塔不出货、和建筑照明有什么关系。  
默认 **Java 1.18+**（含 1.21.x / **26.3**）。基岩版距离和光级规则不同，不要混用教程。

---

## 1. 一句话总览

游戏在玩家周围的区块里，按类别尝试刷怪。敌对生物要同时满足大致这些条件：

1. 难度不是和平；  
2. 位置在合法刷怪距离内；  
3. 脚下的方块表面允许刷怪；  
4. **光照**够暗（1.18 后主世界多数敌对要 **方块光 = 0**）；  
5. 该类别的 **mob cap（数量上限）** 还没满；  
6. 生物群系/高度等额外条件（史莱姆块、溺尸水域等）。

刷怪塔 = 人造「大量合法刷怪点」+「把怪运到处理区」+「尽量别让别处抢帽」。

---

## 2. 距离：太近不刷，太远秒清

Java 常见口径（单人、默认）：

| 距离（相对玩家） | 行为 |
|------------------|------|
| **&lt; 约 24 格** | 自然敌对**不刷**（避免脚边冒怪） |
| **约 24～128 格** | 可刷区间（还要区块加载） |
| **&gt; 128 格** | 多数敌对会立刻视为过远而 **despawn**（名牌等持久化除外） |

实操：

- 挂机点要离刷怪平台 **≥24**，又让平台落在模拟距离内。  
- 处理完的怪要尽快杀掉或移出 cap，否则新怪刷不出来。

多人服：每个玩家都会贡献加载与刷怪压力；帽的计算公式会随加载区块变化——做大型塔前查当前服务端文档。**待核实**你若只打本地单人，可先按 24/128 记。

## 3. 光照（1.18 之后的关键变化）

### 主世界敌对（僵尸、骷髅、苦力怕等常见种）

- **方块光（block light）必须为 0**（完全黑）。  
- 还要看 **天空光（sky light）**：内部天空光过高（大晴天露天）会抑制；洞穴里天空光通常足够低。  
- 1.18 以前：方块光 ≤7 就能刷 → 旧塔「留一点暗」的设计要改成 **全黑平台**。

### 下界 / 末地（摘要）

| 维度 | 粗规则 |
|------|--------|
| 下界 | 无天空光；方块光阈值更宽（常见说法是 ≤7 可刷许多下界敌对）——具体种别仍看 wiki |
| 末地 | 方块光 0 一类规则；末地人等另有条件 |

**对建筑 AI**：生存建筑室内用火把/荧石把方块光抬到 ≥1 即可大幅防刷；刷怪室则要保证平台 **0 光** + 可选半砖防外面乱刷。

---

## 4. 脚下方块：能不能站

敌对通常要刷在**完整顶面**实心方块上。下面这些**常见防刷**（spawn-proof）：

| 做法 | 说明 |
|------|------|
| 下半砖 / 地毯 | 表面不是完整满高，一般不刷 |
| 玻璃、树叶等 | 透明/特殊表面，通常不刷 |
| 按钮、压力板、红石线等 | 占位防刷（线除外情况以 wiki 为准） |
| 水/熔岩 | 非水生敌对不刷在水里等 |

例外（不要以为「全铺半砖就万事大吉」）：

- **史莱姆**：看区块与高度，不完全靠光。  
- **岩浆怪、恶魂、猪灵兽** 等下界规则不同。  
- **溺尸、守卫者** 等水生条件不同。

## 5. 打包刷怪（pack spawning）

游戏不是「一格一只」慢慢刷，而是选一个中心，再在附近尝试刷 **一包** 同类（敌对常见大约 1～4 只量级）。

影响：

- 平台要有一定面积，太碎的单格效率差。  
- 你会看到「一窝僵尸」——正常。  
- 设计水流收集时，要假设怪可能出现在中心周围数格内。

---

## 6. Mob cap（为什么塔会「假死」）

Java 单人维度里，敌对有一个全局帽（常见教材写主世界敌对帽约 **70**；多人会随玩家数缩放）。  
帽满了 → **哪里都不刷**，包括你的塔。

抢帽常见原因：

1. 周围洞穴全黑，外面刷满了；  
2. 漏打的怪堆在加载区；  
3. 命名/乘船等使怪不 despawn，又仍占帽（规则细节见 wiki「持久化」——名牌通常**不占**自然帽，但占实体与性能）。

**洞穴抢帽**是 1.18+ 深世界最大的实战问题：塔很好但附近没照亮 → 效率暴跌。大型塔周边要照亮或用世界边界/海水淹没等手段（进阶见待写 `mob-farm-types.md`）。

## 7. 刷怪塔在干什么（结构拆解）

再花哨的塔也是四段：

```text
[暗平台 / 刷怪空间] → [推挤：水流/活塞/船] → [处理：坠落/岩浆/铁傀儡] → [收集：漏斗]
        ↑
   挂机点距离与照明控制
```

| 类型（预告） | 思路 |
|--------------|------|
| 水瀑/水流塔 | 暗室 + 水流推到坠井 |
| 坠落塔 | 用高度掉血，注意 1.18+ 建筑高度 |
| 传送门塔 | 下界传送门转换猪人等（规则严、版本敏感） |
| 刷怪笼塔 | 依赖地牢/堡垒笼，不是自然帽那套 |
| 试炼刷怪器（1.21） | 机制不同，别当普通刷怪塔教程套用 |

## 8. 和「建筑好看」的冲突

| 建筑目标 | 刷怪需求 | 调和 |
|----------|----------|------|
| 大玻璃窗、采光 | 平台要黑 | 刷怪层无窗；生活区分开 |
| 中空大厅 | 可能变成意外刷怪点 | 半砖/地毯/照明防刷 |
| 紧凑机造风 | 需要 24+ 挂机距离 | 塔体做高或挂机房外置 |
| 装饰用幽匿（1.19） | 振动与监守者 | 别和高频红石农场混在同一振动区 |

**对建筑 AI**：

- 标签可区分 `build_role=habitation` vs `build_role=mob_farm`。  
- 农场景：强制深色地板、完整平台、预留坠井竖井。  
- 住宅景：自动铺照明或下半砖防刷。  
- 导出后建议在超平坦「夜间 + 难度普通」测 5 分钟刷率。

## 9. 版本坑速记

| 版本 | 坑 |
|------|----|
| **1.18** | 敌对方块光 0；世界变高，洞穴抢帽变严重 |
| **1.19** | 深暗之域不是传统挂机塔；幽匿与振动 |
| **1.20+** | 对自然敌对帽无根本改变；注意新生物群系刷怪列表 |
| **1.21** | 试炼刷怪器 / 不祥试炼 ≠ 自然刷怪；女巫掉红石更稳（官方为女巫屋农场友好改过） |
| **26.3** | 刷怪主干仍按现代 Java；新生物群系「斑驳森林」的被动动物变种不影响敌对暗室逻辑 |

## 10. 自查清单（塔不出货时）

1. 难度是和平吗？  
2. 你站得太近（&lt;24）或平台没加载？  
3. 平台方块光是不是 &gt;0（漏了火把/阳光）？  
4. 脚是下半砖/玻璃吗？  
5. 周围洞穴是不是黑的（抢帽）？  
6. 怪是不是堆满没打（帽满）？  
7. 看的是主世界塔却站在下界（或反过来）？
