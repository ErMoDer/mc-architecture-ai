# 作物、甘蔗/竹子与动物农场（原理要点）

讲清楚「长什么条件、怎么收、自动在砍哪一环」，不贴整图逐步工程。  
目标 **Java 26.3**。

参考：[Tutorial:Crop farming](https://minecraft.wiki/w/Tutorial:Crop_farming)、[Sugar cane farming](https://minecraft.wiki/w/Tutorial:Sugar_Cane_farming)、[Bamboo farming](https://minecraft.wiki/w/Tutorial:Bamboo_farming)。

---

## 1. 耕地作物（麦、胡萝卜、土豆、甜菜）

### 生长条件（原理）

| 要素 | 说明 |
|------|------|
| 耕地 | 锄地；缺水会退化；脚踩会踩坏 |
| 水 | 水源影响周边耕地湿度（曼哈顿距离相关） |
| 光照 | 作物需要足够光照才生长（常见要较高方块光；阴暗农场靠灯） |
| 骨粉 | 可催熟；发射器喷骨粉 = 半自动 |

### 自动化两条路

| 路线 | 原理 | 布局含义 |
|------|------|----------|
| **村民农民** | 农民收割+补种；多余食物扔给另一村民；用栅栏挡轨迹让物品落地 → 漏斗 | 需职业站点、床/工作区规划；无红石也能做 |
| **活塞/水分收割** | 破坏成熟作物或冲走；需补种环节（玩家或村民） | 红石时钟或观察者 |

**建筑**：田字格预留水沟与灯柱；村民田要隔开僵尸触碰；漏斗层在地板下。

## 2. 甘蔗

| 要点 | 说明 |
|------|------|
| 种植 | 旁需水（泥/沙/土等可种；**泥巴**上可方便漏斗收物） |
| 高度 | 自然长到 3 格；只砍上面节可继续长 |
| 自动收 | **观察者**发现变高 → 活塞推掉上节；或时钟统一推 |
| 收集 | 泥下漏斗，或水流/漏斗矿车 |

**观察者农场**省事但活塞齐刷可能卡；大型改飞行器收割（区块卸载风险，**待核实**你图的安全停机方式）。

**AI**：沿水岸生成「一排泥 + 后方活塞墙空间 + 观察者层」，不要把甘蔗种在实心地下室无水处。

## 3. 竹子

| 要点 | 说明 |
|------|------|
| 水 | **不需要**水 |
| 高度 | 可长到十几格量级；顶需足够光照才继续长 |
| 用途 | 燃料（单个烧得少，要产量）、脚手架、1.20+ 竹木 |
| 自动收 | 与甘蔗类似：观察者盯高处 → 活塞/飞行器推断 |

**建筑**：院子竖向装饰也可兼产；全自动厂要预留高度与顶灯。

---

## 4. 其它植物（一句话）

| 作物 | 原理抓手 |
|------|----------|
| 南瓜/西瓜 | 梗块旁结果；观察者检测果实 → 活塞推 |
| 仙人掌 | 邻接固体破坏；适合沙漠塔式自动，但伤实体 |
| 地狱疣 | 灵魂沙上；下界农场 |
| 蘑菇/菌光体 | 光照与空间条件特殊 |
| 树场 | 骨粉+飞行器/活塞；占地与卡顿大 |

## 5. 动物繁殖（原理）

| 要素 | 说明 |
|------|------|
| 食物 | 牛羊=小麦；猪=胡萝卜/土豆等；鸡=种子；各自不同 |
| 繁殖冷却 | 一次后进入冷却；幼体成长需时间或喂食加速 |
| 栏容 | 过度挤压会卡实体、影响繁殖与移动 |
| 光照/环境 | 敌对别进栏；下界门等别误伤 |

**建筑**：2×2 或更大栏；半砖顶防跑；门/活板出入口；饲料箱+漏斗投喂可半自动。

---

## 6. 自动宰杀 / 「烤鸡」类（原理）

常见链条：

```text
繁殖区 → 幼体隔离/长大 → 伤害源（熔岩薄层、岩浆块、营火等） → 掉落物漏斗
```

| 注意 | 说明 |
|------|------|
| 只杀成体 | 用落差、水位、活板高度过滤体型（设计核心） |
| 烤熟 | 熔岩/火相关伤害可能直接出熟肉（经典烤鸡） |
| 伦理与服务器规则 | 有的服限制自动屠宰——属玩法政策，不是技术 |
| XP | 玩家附近击杀才有经验；纯自动常只收肉/线/皮 |

**不要**在建筑 AI 里随机生成熔岩房间当「厨房装饰」——必须标 `animal_cooker` 模板并隔离。

## 7. 村民作物联勤（可选）

农民产食物 → 其它村民补库存 → 堆肥桶产骨粉 → 回田。  
涉及职业站点方块与床；和 1.14+ 村庄机制绑定。建筑规划成「田 + 堆肥角 + 工作站」比纯装饰村有用。

## 对建筑 AI / litematic

| 标签建议 | 预留 |
|----------|------|
| `farm=crop_field` | 9×9 田水位、灯、泥/耕地层 |
| `farm=sugarcane_row` | 水沟、泥、活塞墙厚度 1、观察者层 |
| `farm=bamboo_grove` | 竖向净空 ≥12、顶光 |
| `farm=animal_pen` | 栏、顶防逃、饲料箱位 |
| `farm=cooker` | **仅模板**；禁止裸熔岩装饰 |

与红石约束一致：观察者+活塞线用模板粘贴（见 `../redstone/ai-constraints.md`）。
