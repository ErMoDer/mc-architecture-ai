# 防刷与建筑共存（照明、半砖、地毯、城市规划）

目标：房子好看，同时**不在客厅刷苦力怕**；又尽量不让周边洞穴抢走刷怪塔的 mob cap。  
前置：[mob-spawning-basics.md](mob-spawning-basics.md)。Java **1.18+ / 26.3**：敌对方块光须为 **0** 才刷（多数情况）。

参考：[Tutorial:Spawn-proofing](https://minecraft.wiki/w/Tutorial:Spawn-proofing)。

---

## 1. 两条防刷路线

| 路线 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **抬光照** | 火把/灯笼/荧石等，使可站表面方块光 ≥1 | 直观 | 有的审美不想满墙火把 |
| **改表面** | 下半砖、地毯、按钮等不可刷表面 | 可全暗氛围 | 史莱姆等例外仍可能出问题 |

可混用：街道灯笼 + 屋顶平台铺地毯。

---

## 2. 照明要点（1.18+）

- 主世界多数敌对：**方块光 0** 才刷 → 一点光就「防住」该格。  
- 火把照度 14，曼哈顿衰减；社区常按约 **隔 10～14 格**布点起步，再扫暗角。  
- 灯笼/荧石/菌光体/蛙灯等更亮，间距可略放宽。  
- **地毯不挡光**：灯埋地板再盖地毯 = 隐藏照明（都市建筑常用）。

不算在「照明防刷」里的：史莱姆（区块/高度）、岩浆怪、恶魂、猪灵兽等——各查规则。

---

## 3. 半砖 / 楼梯 / 地毯

| 表面 | 通常可刷敌对？ |
|------|----------------|
| 完整顶面实心块 | 可以（再加光照判定） |
| **下半砖** | 否 |
| 上半砖 / 倒楼梯 / 双台阶 | **可以**（易踩坑） |
| 地毯 | 否（现代版本） |
| 玻璃、树叶等 | 通常否 |
| 按钮、压力板、轨道、红石线等 | 常作占位防刷 |
| 泥土小径、耕地 | 偏「非完整」→ 通常否 |
| 泥巴、灵魂沙、雪层 8 | 可能仍可刷——别当安全半砖 |

**屋顶平台**：千万别铺「上半砖装饰」却以为防刷。

---

## 4. 建筑分类处置

| 区域 | 建议 |
|------|------|
| 室内地面 | 灯或地毯；拱廊暗角补灯 |
| 阳台/平顶 | 下半砖或地毯，或栏杆内铺满 |
| 巷道 | 灯柱网格；桥底同样处理 |
| 地下廊 | 必照明；否则变野生刷怪室 |
| 城堡垛口 | 垛口顶面常漏刷——半砖或灯 |

---

## 5. 城市规划（和塔的关系）

1. **分区**：居住区全防刷；农场/塔区允许暗室，但用围墙与门禁隔离。  
2. **道路先定标高**：先路灯网格，再填建筑，少返工。  
3. **地下**：主城下方洞穴必须照亮或填实，否则  

   - 市民被炸；  
   - 你的刷怪塔 **不出货（抢帽）**。  

4. **水域城市**：水面本身不刷多数落地敌对，但桥墩、河床洞穴仍要管。  
5. **材料统一**：灯具造型（灯笼杆 / 荧石藏地毯）定一种，AI 调色板好学。

---

## 6. 与刷怪塔共存的策略

| 策略 | 说明 |
|------|------|
| 高空/深海塔 | 挂机时周围少可刷体积 |
| 周边照明 | 地表+洞穴点亮，逼怪只出在塔内 |
| 海绵式填洞 | 创造/技术服直接填周边洞穴 |
| 别把塔建在主城正下方未照明处 | 互相抢帽又危险 |

---

## 7. 检查流程（生存可执行）

1. 夜晚不开和平，在建筑里走一圈。  
2. 看 F3（或调试）盯脚下方块光。  
3. 听声音：屋顶与桥下。  
4. 对塔：AFK 前后对比周边是否已照明。

## 对建筑 AI

- 住宅标签默认：地面铺地毯或插入灯柱间隔。  
- 平顶生成器用 **下半砖**，禁止「上半砖防刷」幻觉。  
- 城市场景输出 `street_lamp` 结构模板。  
- 见 [ai-layout-notes.md](ai-layout-notes.md)。
