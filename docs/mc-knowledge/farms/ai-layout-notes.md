# 建筑 AI：农场 / 刷怪布局注意事项

把刷怪与农田从「随机装饰」变成「可建造约束」。  
配合：[tower-types.md](tower-types.md)、[spawn-proofing.md](spawn-proofing.md)、`../redstone/ai-constraints.md`。

---

## 1. 硬约束

| # | 规则 |
|---|------|
| 1 | 暗室刷怪区 **禁止**生成火把、荧石、打开的活板漏光 |
| 2 | 中央竖井 / 水道 **禁止**被实心装饰块堵死 |
| 3 | 住宅默认 **防刷**（灯或下半砖/地毯）；与 `farm_type` 互斥区要隔开 |
| 4 | 熔岩处理区仅允许 `template:` 粘贴，禁止当厨房随机熔岩 |
| 5 | 通道净空：玩家走动 ≥2 高；水流层与人行分流 |
| 6 | 漏斗层在建筑底板下预留 1 格设备层 |
| 7 | 挂机平台与刷怪平台欧氏距离体感满足 ≥24，且同图可走 |

## 2. 推荐包围盒（生成预留）

| 类型 | 建议包围盒（可调） | 必留空洞 |
|------|--------------------|----------|
| 小型水冲塔 | 18×18×28+ | 中央 2×2 井到底；每层水沟环 |
| 爬行者层 | 同左，层高约 3（含地板天花） | 2 高净空逻辑；猫/水道位 |
| 甘蔗排 | 长×3×4 | 水沟、活塞墙、观察者槽 |
| 动物栏 | 7×7×4 | 栏门、顶防逃、饲料角 |
| 村民田 | 11×11×4 | 中央水、工作站、床区 |

超出体素网络能力时：**外壳 AI + 内部空气腔标标注**，再套 litematic 模板。

## 3. 标签

| 标签 | 生成行为 |
|------|----------|
| `zone=habitat` | 强制防刷地板 |
| `zone=mob_farm` | 强制暗平台 + 井 |
| `zone=crop` | 田+水 |
| `zone=pen` | 栏 |
| `spawnproof=carpet` | 平顶铺地毯 |
| `spawnproof=bottom_slab` | 平顶下半砖 |
| `template:water_flush_v1` | 粘贴水冲内核 |

---

## 4. 常见 AI 翻车 → 修正

| 翻车 | 修正 |
|------|------|
| 塔很美但满地荧石柱 | 删光源或移到井外灯塔 |
| 竖井被楼梯装饰填满 | 井壁只用栏杆/开放；井芯空气 |
| 田里无水 | 强制每 4～9 格水源规则 |
| 屋顶上半砖「防刷」 | 改下半砖或灯 |
| 动物栏无顶 | 加半砖顶或盖 |
| 城下黑洞洞穴 | 城市生成附带 `cave_light_todo` 标记 |

---

## 5. 与 companion 联调

1. 导出前校验：暗室采样点光级（数据层或人工）。  
2. 超平坦测试世界：夜间放置，AFK 2 分钟看是否出怪。  
3. 失败只换模板，不靠加大 `temperature` 乱刷岩浆。
