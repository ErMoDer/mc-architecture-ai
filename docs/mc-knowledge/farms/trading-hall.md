# 村民交易厅（原理与布局量级）

讲工作站绑定、床与恐慌、交易锁定/补货、僵尸村民消毒折扣，以及建筑 AI 该留多大洞。  
**不是**逐步刷绿宝石教程。目标 **Java 26.3**（与 1.14+ 职业体系一致；折扣规则以 1.20.2+ 为准）。

参考：[Villager](https://minecraft.wiki/w/Villager)、[Village mechanics](https://minecraft.wiki/w/Village_mechanics)。

与农场篇互链：[ai-layout-notes.md](ai-layout-notes.md)、[spawn-proofing.md](spawn-proofing.md)。

## 1. 交易厅在干什么

把「漫游村民」收成：**一人一格、一眼可读交易、能补货、不被僵尸清场**的后勤建筑。

核心三件套（Java）：

1. **职业站点（工作站）** — 决定职业与补货；  
2. **安全隔间** — 防逃、防恐慌踩踏、防刷怪；  
3. **玩家交易窗** — 活板门/栅栏门式开口，村民到不了你身后。

## 2. 工作站绑定（Job site）

| 点 | Java 要点 |
|----|-----------|
| 未交易村民 | 可改职业：靠近未占用工作站并成功认领 |
| 已成交一次 | 职业与交易列表锁定；仍需对应工作站才能**补货** |
| 认领范围 | 失业村民会在较大球体范围找站点（常述约 48 格量级）并寻路靠近 |
| 占用 | 一站一人；成功认领有粒子；他人不会抢已占用站 |
| 补货 | 在站点「工作」可补货，**每天最多约 2 次**（具体日程随游戏日） |

**厅设计含义**：每个隔间放**正确**工作站，且村民身体要能「够到」站点（矿车里也能补，只要站点可达——以实测为准）。拆掉站点后已锁定职业的村民**不会忘交易**，但会**补不了货**。

## 3. 床：Java 交易厅要不要？

| 用途 | Java 交易厅 | 说明 |
|------|-------------|------|
| 补货 / 交易 | **不需要床** | 与基岩版不同（基岩常要床链接） |
| 繁殖 | 需要多余床 | 繁殖厅与交易厅宜分开 |
| 村庄 POI | 床=「房屋」定义之一 | 床太多可能拉长村庄半径、引袭击/铁傀儡等——大厅密集床要有心理准备 |
| 消毒加速 | 附近的床、铁栏杆可**加速**僵尸村民治愈 | 单独消毒室很有用 |

**结论**：纯交易厅可无床；繁殖与消毒另区规划。

## 4. 恐慌、袭击与安全

| 风险 | 原理级对策 |
|------|------------|
| 看见僵尸/袭击者恐慌 | 隔间不透视到敌对，或隔断视线；通道防怪进入 |
| 硬难度僵尸破门 | 门外挖沟、门扇朝向、地毯坑等传统防破门 |
| 雷暴/闪电 | 屋顶避雷与遮挡；图书管理员别被劈成女巫（概率事件，厅要封顶） |
| 玩家误伤 | 开口高度只到手，打不到村民头 |

照明与半砖防刷见 [spawn-proofing.md](spawn-proofing.md)。

## 5. 交易解锁、涨价与「消毒」折扣

### 锁定职业

1. 失业村民 + 目标工作站 → 出现交易；  
2. **成交至少一次** → 职业与列表锁定；  
3. 不满意就在锁定前拆站重滚（图书管理员滚书）。

### 补货与涨价

- 某项卖光会暂时锁定，工作后补货。  
- 需求机制会涨价；长期只砸一项会越来越贵。  
- 「村庄英雄」等可临时降价（袭击相关）。

### 僵尸村民治愈（消毒）

```text
虚弱（喷溅药水等）+ 金苹果 → 约数分钟转化回村民
```

| 点 | 说明 |
|----|------|
| 折扣 | 治愈后多数交易降价 |
| **不可叠砍** | 约 **1.20.2+**：同一村民反复感染再治愈**不再叠加**额外大折扣；第一次大折扣即可 |
| 难度 | 僵尸转化村民概率与难度有关；简单难度可能直接打死而非转化 |
| 建筑 | 独立消毒室：遮光、铁栏杆/床加速、与正厅隔离 |

金苹果常来自金农场（见 [spawner-farms.md](spawner-farms.md) 猪人/传送门摘要）。

## 6. 常见厅布局量级（原理级）

| 元素 | 常用量级 | 说明 |
|------|----------|------|
| 单人隔间 | **1×1** 站位 + 前后墙 | 矿车/船固定也可 |
| 工作站 | 隔间内或邻格可触及 | 讲台常放脚边/头顶可达处 |
| 交易窗 | 活板门一行 / 栅栏门 | 玩家站外、村民站内 |
| 层高 | ≥3 | 防窒息、方便放站 |
| 通道 | ≥2 宽 | 推矿车、逃生 |
| 规模 | 十几～三十人常见 | 服务器可能另有人数/区块规则（**待核实**你服规） |
| 与基地距离 | 有的技术服建议交易厅放较少常加载处 | 减实体卡顿；单人随意 |

双排隔间 + 中央走道是最稳构图；旋转楼梯上二层扩容。

## 7. 对建筑 AI 的预留

| 标签建议 | 预留 |
|----------|------|
| `zone=trading_hall` | 走廊 + 两侧 1×1 腔体阵列；每腔预留工作站方块位 |
| `station=lectern` 等 | 腔体放对应站点，勿放错职业 |
| `zone=curing_cell` | 3×3×3 遮光室，铁栏杆装饰合法 |
| `zone=breeder` | **分开**；床阵列，勿与交易腔混用 |

硬规则：

1. 禁止把村民生成进无站点的封闭装饰盒（假村民房）。  
2. 禁止大厅地板漏刷（地毯/灯）。  
3. 站点朝向不敏感者优先；酿造台等保持可交互面朝通道。  
4. 机械（驱逐、时钟）用模板，遵守红石 AI 约束。
