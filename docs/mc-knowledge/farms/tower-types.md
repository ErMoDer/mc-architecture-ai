# 常见敌对刷怪塔类型（原理与布局约束）

讲「为什么能出货 / 该留多大洞」，**不是**逐步建造作弊图。具体尺寸因版本与设计而异，下文数字是社区常用量级，落地请创造模式实测。  
前置：[mob-spawning-basics.md](mob-spawning-basics.md)。目标 **Java 26.3**。

参考：[Tutorial:Mob farm](https://minecraft.wiki/w/Tutorial:Mob_farm)、[Tutorial:Mob grinder](https://minecraft.wiki/w/Tutorial:Mob_grinder)、[Tutorial:Creeper farming](https://minecraft.wiki/w/Tutorial:Creeper_farming)。

---

## 1. 通用骨架（所有塔都长这样）

```text
暗平台（可刷） → 收集通道（水/猫/活塞） → 处理区（摔/岩浆/营火…） → 漏斗仓储
        ↑
   挂机点距离（约 24～128）+ 周边勿抢 mob cap
```

| 约束 | 常用量级 | 说明 |
|------|----------|------|
| 平台方块光 | **0**（1.18+） | 漏火把就不出货 |
| 玩家距离 | ≥约 24 才刷；≤约 128 才保持 | 挂机点别站平台上 |
| 屋顶净空 | 看目标怪 | 2 高偏爬行者过滤；3 高易进末影人等 |
| 坠落击杀 | 约 **22～24** 格对多数 20HP 敌对 | 女巫更耐摔（常提到约 30）；带摔落保护盔甲会例外 |
| 打包 | 平台要成片 | 太碎的单格效率差 |

蜘蛛会爬墙——竖井要处理（滑块、水帘、额外宽度等），否则堵塔。

## 2. 水推 / 水冲塔（Water flush）

**原理**：暗室刷怪 → 水流把怪冲进中央竖井 → 坠落或下游处理。

| 布局要点 | 说明 |
|----------|------|
| 水道 | 每层平台分水沟；水源与流动方向要覆盖刷怪面 |
| 主动冲刷 | 发射器倒水 + 时钟/观察者，周期性淹平台（不靠怪自己走路） |
| 被动引诱 | 活板门/栅栏门「骗路径」让怪走向缺口 |
| 选址 | 深海/高空：少洞穴抢帽 |

**适合**：通用掉落物塔。  
**AI**：预留「层高 + 中央竖井 + 周圈水沟」；不要把竖井用实心块封死。

---

## 3. 坠落处理（Fall）

**原理**：摔落伤害；可配「留半血手动刀」换经验与抢夺。

| 要点 | 说明 |
|------|------|
| 高度 | 全自动击杀常取 ≥24；半血经验房略矮（常见谈 22） |
| 免疫 | 鸡、铁傀儡、部分飞行怪等不吃摔落——别当万能 |
| 蜘蛛 | 会爬井壁，需防爬设计 |
| 女巫/末影人 | 女巫回血、末影人传送——全自动图常另案 |

底部：漏斗/漏斗矿车收集；经验房开「只露脚」的窗口防被打。

---

## 4. 岩浆刀 / 岩浆刮（Lava blade）

**原理**：薄层熔岩刮过怪的头部/身体，物品掉下落入通道。

| 要点 | 说明 |
|------|------|
| 物品 | 熔岩会烧掉部分掉落物——火药塔慎用熔岩 |
| 时序 | 需活塞/信号控制刀片进出，避免烧箱 |
| 安全 | 机房与玩家通道隔离熔岩 |

现代很多图改用**营火 / 岩浆块**代替真熔岩刀，掉落物更安全。

---

## 5. 岩浆块 / 营火处理

| 方式 | 原理 | 注意 |
|------|------|------|
| 岩浆块 | 站上去持续烧血 | 较慢；可用漏斗矿车在下方收物；水流会干扰站立伤害 |
| 营火 | 持续伤害且不烧物品（相对熔岩） | 爬行者火药塔常用；上方可用告示牌挡水 |

---

## 6. 爬行者专用塔（原理）

**目标**：只出爬行者 → 火药。

常用过滤思路（原理级）：

1. **高度**：净空约 2 格，配合活板门，让僵尸/骷髅难刷、爬行者可刷。  
2. **猫**：爬行者怕猫，被驱赶进水道/门户（替代部分活塞推）。  
3. **名称/地毯等**细节各图不同——以你跟的版本教程为准。  
4. **处理**：营火/岩浆块；要头颅则另接闪电苦力怕逻辑（进阶）。

**布局**：多层暗场 + 中央收集；挂机点拉高并照亮周围地表/洞穴提速。

---

## 7. 其它常见变体（一句话）

| 类型 | 原理摘要 |
|------|----------|
| 传送门塔 | 利用下界传送门转换/转运实体；规则严、易坏，跨版敏感 |
| 刷怪笼塔 | 依赖地牢/堡垒**刷怪笼**，不是自然 mob cap 那套 |
| 蠹虫/烈焰人等 | 特殊维度与结构条件；别套主世界水冲图 |
| 试炼刷怪器（1.21） | 机制不同，不是暗室自然塔 |

---

## 8. 效率杀手（设计时就要防）

1. 周边洞穴全黑 → **抢帽**（1.18+ 更严重）。  
2. 挂机太近（&lt;24）或太远（怪 despawn / 不刷）。  
3. 平台漏光。  
4. 竖井被蜘蛛或舟船堵死。  
5. 熔岩烧掉要的掉落物。  
6. 和平模式 / 难度不对。

## 对建筑 AI

- 标签 `farm_type=water_flush|creeper|xp_drop` 决定预留竖井高度与层高。  
- 生成「好看的塔皮」时必须保留：**暗室体积、中央井、底层漏斗层**。  
- 齐平装饰屋顶用上半砖/玻璃时，确认不会破坏方块光 0。  
- 详见 [ai-layout-notes.md](ai-layout-notes.md)。
