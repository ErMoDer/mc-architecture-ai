# 农场 / 刷怪版本坑（Java → 26.3）

专门收「换版本后塔废了 / 教程过时了」。细节机制见 [mob-spawning-basics.md](mob-spawning-basics.md)。

参考：[Mob spawning](https://minecraft.wiki/w/Mob_spawning)、[Java 1.18 feedback](https://feedback.minecraft.net/hc/en-us/articles/4415128577293-Minecraft-Java-Edition-1-18)。

---

## 1. 1.18：光级与世界（最大坑）

| 变更 | 后果 |
|------|------|
| 敌对多数要 **方块光 0** | 旧「光级 1～7 还刷」的暗室/防刷思路过时；防刷更容易（一点光就行） |
| 世界高度 -64～319、洞穴巨大 | **洞穴抢帽**成为刷怪塔第一杀手 |
| 怪物帽改为更偏向 **按玩家** | 多人服每人贡献压力；设计 AFK 点要考虑 |

**行动**：旧塔先检查漏光；再照明周边洞穴或迁到深海/虚空世界。

## 2. 打包（Pack spawning）相关误解

- 刷怪按「包」尝试，中心点选在区块里；中心若落在不合法位置，整包可能浪费。  
- 平台要有连续面积，利于包内偏移仍落在暗平台上。  
- 顶铺半砖「只为防日光」时，确认半砖方向不会毁掉可刷面（见 spawn-proofing）。

精确分布参数随版本微调——优图以当前 26.3 实测为准，**待核实**你跟的技术向视频的年份。

## 3. Mob cap 与「假死塔」

| 现象 | 常见原因 |
|------|----------|
| 塔内空、外面嗷嗷叫 | 洞穴/地表抢帽 |
| 突然不出货 | 加载区堆满未处理怪；或和平/难度 |
| 降模拟距离后怪异 | 懒区块/加载行为可占帽——低模拟距离需格外小心（机制论述见社区文，**待核实**当前 26.3 默认模拟距离表现） |

名牌持久化等规则影响「占不占帽」——与开关类技术有关，见 wiki Mob switch；建筑向只需知：**别乱命名一堆敌对堆在加载区**。

---

## 4. 1.19：深暗与幽匿

- 深暗之域 / 监守者 **不是**传统水冲塔思路。  
- 幽匿传感器：振动红石；农场高频活塞可能误触发（与红石篇联动）。  
- 古城强化深板岩等：可作题材，不可当普通刷怪平台期望。

## 5. 1.20–1.21

| 点 | 农场影响 |
|----|----------|
| 竹木/樱花 | 装饰与竹自动场材料变多 |
| 合成器 | 掉落物自动合成线（火药→TNT 等）更容易 |
| 试炼刷怪器 / 宝库 | **另一套机制**；教程不能和暗室自然塔混用 |
| 女巫掉红石更稳等小改 | 女巫屋农场叙事变好（具体数值以 wiki） |

---

## 6. 26.3 相关

- 自然敌对刷怪主干仍是现代 Java（光 0、打包、距离）。  
- 新生物群系（斑驳森林等）主要改被动动物变种与建材；**暗室敌对塔逻辑不依赖杨木**。  
- 羊毛楼梯/台阶：可作消振与防刷表面（建筑向加分）。  
- 草垫床等不影响刷怪公式。

---

## 7. 作物 / 动物侧过时点

| 旧假设 | 现状 |
|--------|------|
| 甘蔗只能沙土 | 泥巴等可种，且利漏斗 |
| 竹子只是装饰 | 可大型自动燃料/竹木工业（1.20+ 竹木） |
| 村民耕地共享食物无阻挡 | 1.14+ 职业体系下要用工作站/栏设计 |
| 熔岩刀通杀所有掉落 | 火药等会被烧——爬行者塔改营火 |

---

## 8. 跨版（Java vs 基岩）

- 刷怪距离、帽、光规则不同。  
- 同一「水冲塔」蓝图不要当跨版通用。  
- companion / 本知识库默认 **Java 26.3**。

## 对 AI

生成农场建筑时写入元数据：

```text
farm_mechanics=java_1_18_plus_light0
target_version=26.3
```

旧训练数据若来自「光级≤7」时代叙事，不要写进用户文档当现行规则。
