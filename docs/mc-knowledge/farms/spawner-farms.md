# 刷怪笼农场与相关摘要（传送门 / 猪人）

刷怪笼（Monster Spawner）是**结构自带**的刷怪方块，机制与暗室自然塔不同。  
本文讲激活距离、刷出体积、光照、僵尸/骷髅/蜘蛛要点，并附传送门金与猪人相关**原理摘要**。  
**不是**逐步最优速率工程图。目标 **Java 26.3**。

参考：[Monster Spawner](https://minecraft.wiki/w/Monster_Spawner)、[Monster spawner traps](https://minecraft.wiki/w/Tutorial:Monster_spawner_traps)、[Zombified Piglin farming](https://minecraft.wiki/w/Tutorial:Zombified_Piglin_farming)、[Bartering](https://minecraft.wiki/w/Bartering)。

互链：[tower-types.md](tower-types.md)、[mob-spawning-basics.md](mob-spawning-basics.md)、[trading-hall.md](trading-hall.md)。

## 1. 和自然塔的本质区别

| | 刷怪笼 | 自然暗室塔 |
|--|--------|------------|
| 刷怪来源 | 笼方块尝试生成 | 世界自然刷怪算法 |
| Mob cap | 仍受实体/附近数量等限制，但逻辑不同 | 强依赖全局/玩家帽与抢帽 |
| 选址 | 找到地牢/堡垒/要塞等现成笼 | 自建平台 |
| 光照 | 笼周围刷出区要够暗（烈焰人等更严） | 平台光 0 |

不能把「水冲自然塔」教程数值直接套到笼上。

---

## 2. 激活距离（Java）

- 非旁观玩家进入以笼**中心**为球心、半径约 **16 格**的范围即激活。  
- 判定常用**脚部坐标**：站得「头够得到、脚差一截」可能**不激活**——挂机点要按脚算。  
- 激活后周期性尝试刷怪（间隔大约十余秒到数十秒量级，带随机），每次尝试刷最多约 **4** 只。

**建筑**：AFK 台距笼 &lt;16；过远笼休眠，过近可能不好做安全击杀位。

---

## 3. 刷出盒（Spawn volume）

Java 活跃笼在笼周围尝试找合法落点，水平约 ±4、垂直约 ±1，即大约 **9×3×9** 体积（以笼为中心）。  
落点还要满足该生物碰撞箱与光照等，因此实际要挖开的工作区往往比「刚好 9×3×9」更大一点。

| 生物 | 工作区直觉（Java） |
|------|-------------------|
| 僵尸 / 骷髅 | 要约 2 格高站立空间；水平掏足 ±4；常**往下多挖**让怪掉出刷出盒，避免占位卡刷 |
| 蜘蛛 | 更宽更扁；高度需求较低但水平更挑 |
| 洞穴蜘蛛 | 可过一格缝，危险；围栏与管道要更密 |
| 烈焰人 | 光照抑制更严（常见「要很高光才彻底关笼」）；下界堡垒场景 |

社区经验量级（非唯一标准）：僵尸/骷髅常「上挖约 2、下挖更深（数格）」；蜘蛛略有不同——以创造清笼实测为准。

**占位**：刷出盒里已有同种大量怪会抑制继续刷——尽快把怪**移出盒**（水流、落井）。

## 4. 光照

| 类型 | 关笼 / 开刷 |
|------|----------------|
| 多数主世界笼（僵尸骷髅蜘蛛） | 刷出区方块光 **0** 才好刷；一支火把插笼上常可**关闭**简易笼 |
| 烈焰人 | 抑制需要更高光照覆盖整个刷出区，单火把往往不够 |

白天露天地牢若天空光够高也可能影响；技术塔通常封顶做暗室。

## 5. 僵尸 / 骷髅 / 蜘蛛笼要点

### 僵尸笼

- 掉落腐肉、铁锭偶尔、胡萝卜土豆等；可接溺尸转化玩铜（进阶，有额外机制）。  
- 强化召唤（被攻击时概率招援）可被部分设计利用——复杂且版本敏感，**待核实**后再上模板。  
- 处理：落井、营火、玩家刀口；注意僵尸村民别误杀（可留作消毒，见交易厅）。

### 骷髅笼

- 骨与箭；远程危险 → 击杀窗要用栅栏/墙缝限制射角。  
- 同样需要暗与移出刷出盒。

### 蜘蛛笼

- 线与蜘蛛眼；会爬 → 竖井与管道防爬。  
- 洞穴蜘蛛有毒、更瘦 → 默认当高危笼，管道用实心+小孔视角杀。

### 简易 XP 布局直觉

```text
暗化并扩大刷出区 → 水推入井 → 坠落半血或隔离刀口 → 漏斗
```

与 [tower-types.md](tower-types.md) 坠落/营火原则相同，只是「刷怪源」换成笼。

## 6. 附属摘要：传送门金与猪人

> 以下为原理摘要，便于和交易厅（金苹果）联动；完整工程另文待写。

### 6.1 僵尸猪灵与金

| 路线 | 原理 | Java 粗评 |
|------|------|-----------|
| 下界自然刷 | 下界荒地等平台刷僵尸猪灵再收集 | 常作为高效金来源方向 |
| 主世界传送门 | 传送门方块随机刻可能刷出僵尸猪灵 | 好建、偏慢；注意愤怒猪灵窜维度 |

传送门农场注意：愤怒实体经门回流、冷却、用海龟蛋等引离门——防「回家被群殴」。

### 6.2 猪人以物易物

- 猪人必须在**下界**（主世界会转化）。  
- 金锭换随机战利品；Java 单次审视大约 **6 s** 量级。  
- 穿金防具减敌对；远离灵魂火类方块以免乱跑。  
- 金粒→锭自动合成再投入猪人栏，可与金农场对接。

与交易厅：金苹果消毒村民 ← 金农场/猪人线。

## 7. 版本与坑

| 坑 | 说明 |
|----|------|
| 脚部激活 | AFK 台差半格不刷 |
| 盒内囤怪 | 不冲走就假死 |
| 火把关笼后忘记拆 | 「塔坏了」 |
| 烈焰当普通笼照 | 关不干净 |
| 基岩刷出形状不同 | 教程勿混 |
| 试炼刷怪器（1.21） | **不是**地牢 Monster Spawner，机制另算 |

26.3：地牢笼规则仍属现代 Java；勿与试炼室刷怪器混淆。

## 8. 对建筑 AI

| 标签 | 预留 |
|------|------|
| `zone=spawner_room` | 以笼为中心 ≥9×9 水平开挖标记；上 2 / 下数格空气腔 |
| `spawner_mob=zombie\|skeleton\|spider` | 决定层高与防爬 |
| `afk_pad` | 距笼中心 &lt;16 的安全台 |
| `zone=portal_gold` / `zone=barter` | 仅模板区；勿随机门堆 |

硬规则：

1. AI **不能**「生成」可捡的刷怪笼（生存不可丝绸之路搬）；只能识别已有笼坐标做壳。  
2. 装饰灯禁止插进刷出盒。  
3. 水流层与人行通道分离。
